## Main post (under 280 chars)
I built RedLoop for the @AIatMeta hackathon: an agent that red-teams AI agents.

It hides prompt injections in email, Slack, GitHub and screenshots, judges every tool call, and turns any breach into a CI test.

Muse Spark held: 0/111 live breaches.

github.com/arthi-arumugam-git/redloop

## Reply 1
Why: agents that read your inbox and then call tools can be steered by text hidden in that content. Most teams have no repeatable way to prove a fix stays fixed. RedLoop freezes every past attack into a regression suite and a GitHub Action that fails the build if one gets through again.

## Reply 2
The live runs still caught something: Muse Spark looped guessing document IDs. Adding a list_docs tool fixed it, and those scenarios now finish in 2 tool calls. A full 65-case sweep costs about $1.16, cheap enough to run on every PR.
